面向前列腺癌患者与照护者的本机优先工作台：病理与 PSA 读懂、ADT 身体与生活、排尿与性功能康复、主动监测、复诊准备与临床试验档案

### 定义

前列腺癌是发生在前列腺上皮的恶性肿瘤，最常见的是腺泡腺癌。确诊依据是穿刺或手术标本的病理；**PSA 是监测与提示指标，不是诊断结论**——PSA 升高本身不能确诊，PSA 在参考范围内也不能排除。本台只存 PSA 数值、日期、检测单位与报告原文，不写「PSA 高了说明什么」。

三个维度必须分开，这是本项目最容易写错的地方：

- **病理分级**：Gleason 评分与 ISUP 分级分组是**同一件事的两种表述**。ISUP 分组由 Gleason 评分换算而来（例如 3+4=7 对应 ISUP 2 组，4+3=7 对应 3 组，8 分对应 4 组，9–10 分对应 5 组）。它们不是两套独立评分，不能并列比较、不能相加。
- **分期**：TNM（版本未核实），描述局部侵犯范围、淋巴结与远处转移。
- **风险分组**：把 PSA、Gleason / ISUP 与分期放在一起得出的判断（低危 / 中危 / 高危这类分档），属医生结论。本台只抄原文，不自己算。

`docs/BRIEF.md` 记录的目标用户是新确诊或治疗中的患者（60–75 岁男性为主）与代记资料的配偶 / 子女；本台不把医生任务写成患者任务。

### 目前治疗全景概要

按病期与治疗目的分组，只列指南里出现过的**手段类别**，不含剂量、疗程与选择条件。

- **局限期**：主动监测（特定情形下被列为一条路径）／根治性前列腺切除／放疗（外照射、近距离照射两类）——这三类并列存在，选哪一条属医生与你共同判断。
- **局部晚期**：放疗联合雄激素剥夺治疗（ADT）；手术在特定情形下被讨论；ADT 联合新型内分泌治疗这一类别。
- **转移性**：以 ADT 为基础；联合新型内分泌治疗类别、化疗类别；HRR 基因突变情形下的 PARP 抑制剂类别；骨转移的放射性配体治疗类别（国内获批状态与可及性需单独核实）。
- **贯穿全程**：PSA 复查节奏（只记数值与日期）／骨健康、排尿功能、性功能、潮热与乏力等身体变化的**自评记录**——本台不给总分、不画评分、不与人比。

以上是文献与指南里列出的手段，按病期与线序排列，**不代表任何一项适合你**。选哪一个，这一句需要问你的医生。

## 开发与本地验收

需要 Node.js 22+、Git、包管理器和可用 DSH Desktop；采用 SQLite 时另核验 node:sqlite 版本条件。宿主 peers 的范围仅是模板基线，请与目标 Desktop 实际依赖核对。

```bash
npm install
npm run check
npm run pack:check
npm pack
```

`npm install` 可能按 npm 策略解析 peer；勿为消警告重复打包宿主 runtime。客户端本身是单文件；引入 TS/组件库后需添加构建步骤并保留单文件导出。

本地安装入口以当前 Desktop/CLI 帮助为准。安装后按 [docs/06-VALIDATION-AND-RELEASE.md](docs/06-VALIDATION-AND-RELEASE.md) 与官方自测完成真实 UI 验收，并填写 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。静态检查不代表已加载。

Logo 来源与使用限制见 assets/README.md。许可证、作者、仓库/发布策略由本项目维护者确认后填写；模板默认为 private/UNLICENSED。
