# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：新确诊或正在治疗的前列腺癌患者本人（60-75 岁男性为主），以及代记资料的配偶/子女照护者

场景：患者拿到一份穿刺病理和一张 PSA 化验单，看不懂 Gleason/ISUP 与分期；正在做去势治疗，潮热乏力性功能变化没人可问；下次门诊想带一份说得清的材料

核心流程：
1. 把病理、PSA、影像原文抄录/导入，标注哪些还没核对
2. 在分型与风险页看到自己的 Gleason/ISUP、分期、风险组原文，知道哪些要问医生
3. 在治疗历程记录当前路径（主动监测/根治术/放疗/ADT/新型内分泌）与实际用药、周期
4. 在身体与生活页记潮热、体力、骨健康、排尿、性功能与情绪，选择哪些可分享
5. 生成一份复诊摘要，带去门诊；把想问的问题与试验线索一起收好

完成结果：患者能用自己的话说清得的是哪一类、现在走到哪一步、这次复查要问什么；照护者能接手记录而不丢信息

初始布局选择：business-first
